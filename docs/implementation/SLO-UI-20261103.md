# Painel administrativo de SLOs — 03/11/2026

O contrato `agentControlSloReportSchema` (`AgentControlSloReport`) é zod strict e descreve `GET /api/v1/ac/observability/slo`: `schemaVersion` 1, `catalogVersion` 1, `scope` `installation_aggregate` e exatamente cinco resultados distintos (`manager_availability`, `dispatch_latency`, `queue_backlog`, `pending_receipt_age`, `infrastructure_failure_rate`), cada um com `version` 1, `status` `ok|violated|unknown`, `reason` string livre, margem `ppm|count|seconds` com `headroom` string livre ou `null`, e janela `snapshot_point` com `observedAt` e `ageSeconds` string ou `null` e `freshnessLimitSeconds` qualquer número finito. Decisão de contrato do gerente: o catálogo é fechado, então ids ausentes, duplicados ou extras tornam o relatório indisponível. O api-client já reexporta o contrato (`export * from '@open-mercato/cezar-contract'`). O painel em `agent-control-observability.tsx` lê esse GET com `agentControlFetch` e o escopo de projeto existente: no shell gerenciado o id do projeto vem da rota, então a consulta ocorre; sem id de projeto a tela não chama o endpoint e mostra indisponível, nunca “dentro do objetivo”. Cada indicador traz rótulo em português, estado em texto, motivo, margem e a própria janela (frescor e idade); não há idade geral copiada do primeiro resultado. `violado` traz a palavra e `role="alert"`; `desconhecido` explica que não é cumprimento. Reason com espaços e headroom com 19 dígitos são aceitos e renderizados. Idade negativa conserva o sinal, inclusive um valor grande (`-3` permanece `-3 segundos`). Rede, HTTP não ok, JSON inválido, corpo fora do schema ou falha de atualização mostram só a indisponibilidade com “Tentar novamente”, sem o relatório anterior e sem eco do corpo. Isto não prova aparelho físico, não cria a rota no servidor, não usa PostgreSQL e não aceita os 111 requisitos. `node_modules` presente; `dist` de contract ausente e não exigido, porque o web resolve o fonte. Comandos desta correção: `npm --prefix upstream/cezar run typecheck -w @open-mercato/cezar-web` exit 0; `npm --prefix upstream/cezar test -w @open-mercato/cezar-web -- --run src/routes/settings/agent-control-observability-slo.test.tsx` exit 0 (11 testes).
