# Equipe CORE — 02/11/2026

Runtime dinâmico sintético integrado e exercitado em bancada. Nenhum gate de produção ou runtime de inferência real declarado.

## Distribuição e contratos

Gerência: `/root/manager_core`, Sol 6.1 Médio. Quatro executores Terra Médio, com ownership separado: A (`/root/terra_probe`) receita, ledger, Cezar e migração 036; B implementação isolada, engenharia e integridade/composição Git; C cancelamento, broker e verificadores; D revisão independente e contraprovas. Não houve criação de executores adicionais. Arquivos administrativos, frontend e documentos canônicos pertencem ao root/outra gerência.

A receita congelada mantém Cezar como única autoridade do DAG. Filhos têm `parent_intent_id` e `parent_unit_id` imutáveis, contexto compartilhado e não recebem outbox própria. `readManagedUnit` valida receita, digest, identidade e vínculos; `ManagedExecutionInput` congela base e escopo por unidade. O comando managed usa `workflow: managed-synthetic-v1`, `proposalRevision`, `proposalDigest` e `messageRef`. A ativação administrativa permanece subordinada ao runtime disponível.

Cada unidade precisa de cópia separada e caminho de saída dentro do escopo congelado. Composição exige fontes aprovadas, ordem congelada, novo artefato, QA/revisão próprios e CAS exato. O helper Git é código confiável do controlador; sua execução local não é prova de sandbox Docker. Composição não pode fabricar recibo para satisfazer Quality: requer grant próprio, identidade física, saída observada e incerteza conservada nos intervalos sem prova.
