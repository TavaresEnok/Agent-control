# R5 — redação de credenciais nativas: escopo em avaliação

O ELF público local `codex-cli 0.166.0`, SHA-256 `b8a11fedf24b2dfb59a70c9e52b030f9a508dcd49cd2dd0d41956f4c785156b8`, gerou bindings TypeScript com `app-server generate-ts --experimental`, sem rede. Os tipos locais descrevem `account/login/start` com `chatgptAuthTokens` e a solicitação servidor→cliente `account/chatgptAuthTokens/refresh`. Um laboratório Docker com rede `none`, HOME temporário e JWT sintético comprovou apenas a aceitação local do formato pelo executável; não houve autenticação oficial nem inferência. Evidência `r5-external-auth-offline.log`.

O worker nativo proposto usa CODEX_HOME privado temporário, vincula a identidade das credenciais lidas ao snapshot anterior por HMAC e inicia o modo externo. A renovação é recusada por padrão, sem classificá-la como logout ou quota esgotada. O runner possui callback privado opcional que valida conta e registra o novo valor antes da resposta; esse callback é uma interface interna, **não é uma autoridade autenticada de renovação implementada no produto**. O worker não o fornece. Ativação de renovação requer autoridade autenticada, fencing e atualização durável do conjunto de redação antes de entrega. Credenciais ou tokens arbitrários não classificados não são reconhecidos por promessa genérica.

Resultados nativos são redigidos com valores de capability e campos textuais estruturados do contêiner `tokens` de auth; o identificador da conta não é tratado como segredo. Logs Docker são validados como frames não-TTY, decodificados por stream, redigidos antes da gravação e vinculados aos recibos pelo hash dos bytes redigidos. Isso preserva ordem dentro de cada stream, não ordem relativa entre stdout e stderr. Contexto de redação indisponível produz um diagnóstico fixo. Logs legados já vinculados a SHA são preservados criptografados em quarentena mantendo o hash original, sem modificar o recibo; a restauração de plaintext não é exposta por este mecanismo. Toda mudança aguarda revisão independente e ensaio físico do worker nativo completo.
