### Sinais

- **Média — `SIG160` vira evidência de alerta.** Em `timeout --signal=SIG160 30s npm run personal:watch`, o coletor retira `SIG` antes de aplicar a máscara numérica e aceita o resultado `32`. No GNU 9.7, a máscara só se aplica quando o argumento original começa com um dígito. `SIG160` é rejeitado e a rotina de alerta não inicia. ### Posição do executável após `--`

- **Média — expansão sem aspas pode deslocar o executável.** Em `timeout -- $LIMITE 30s npm run personal:watch`, se `LIMITE` estiver vazia ou indefinida, o shell pode remover o argumento. Nesse caso, `30s` é a duração e `npm` é o executável. O coletor fixa `30s` como executável e pode emitir `PRONTIDAO-ALERTA-AUSENTE` com cobertura `ok`. O caso entre aspas coberto pelo teste mantém o argumento vazio e tem outro resultado.
