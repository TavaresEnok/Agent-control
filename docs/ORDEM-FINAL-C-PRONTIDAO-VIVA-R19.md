- **Alta — padrões simples incompatíveis produzem prova positiva.** Em `find . -name 'backup.sql' -name 'archive.sql' -mtime +7 -delete`, cada padrão passa isoladamente. A conjunção é impossível e `-delete` nunca é alcançado, mas o coletor registra retenção. [audit-readiness.mjs](/home/app/projects/agent-control/deploy/modules/prontidao/audit-readiness.mjs:2296)
- **Média — destino de redirecionamento vira comando.** No corpo de `bash -c` `echo >&df -P /; echo "`, `df` é o destino do redirecionamento. O recuperador separa no `&` e envia `df -P /` ao classificador como outro comando, marcando disco como parcial indevidamente. [audit-readiness.mjs](/home/app/projects/agent-control/deploy/modules/prontidao/audit-readiness.mjs:2421) · [Manual Bash](https://www.gnu.org/software/bash/manual/html_node/Redirections.html)
- **Média — espaço escapado dentro de `$()` faz a recuperação perder um comando externo.** No corpo `echo "$(printf '%s' x\ #)"; df -P / "`, o `#` pertence ao argumento `x #`. O recuperador olha o caractere anterior, interpreta o `#` como início de comentário e abandona a leitura antes do `df`. Disco perde a cobertura parcial.
