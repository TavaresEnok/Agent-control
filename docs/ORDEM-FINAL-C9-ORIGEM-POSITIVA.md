1. **[P2] Chamadas locais encadeadas perdem efeitos nos dois analisadores.** Uma função sem argumentos chama outra função, declarada dentro dela, que troca `emit` por uma função vazia. O Python exclui do resumo as chamadas a nomes locais. O JavaScript segue declarações de função nesse caso, mas deixa passar `const stop = () => { … }`. Depois da chamada externa, `emit` continua classificado como destino de log. 2. **[P2] Um alias local pode ocultar a mutação de um receptor externo.** Se uma função faz `alias = tray` e sobrescreve `alias.slot` com um literal neutro, os dois resumos descartam `alias` por ser local. A leitura posterior de `tray.slot` ainda pode apontar para a origem anterior. O caso cabe no subconjunto nominal e pode ser tratado acompanhando o alias direto ou invalidando o receptor dependente com cobertura parcial. 3. **[P2] O Python descarta uma escrita global ao analisar o corpo de outra função.** Se `outer()` declara `global emit`, atribui `print` a `emit` e chama uma função interna que redefine esse mesmo global, `apply_effects` ignora a escrita porque seu proprietário é `None` e `self.function` é `outer`. Assim, `print(chosen["quartzSignal"])` pode gerar um achado para um valor neutro, mesmo com cobertura parcial já registrada.
